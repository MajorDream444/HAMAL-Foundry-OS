## Working rules

- Distinguish current capability from roadmap.
- Label material claims: VERIFIED, AVAILABLE, CONFIGURABLE, REPORTED, INFERENCE, PROPOSAL, OPEN, or CONFLICT.
- A file is not canonical merely because it exists in this repository.
- Treat generated summaries, podcasts, and presentations as derived material, not corroborating evidence.
- Keep consequential actions human-authorized.
- Do not introduce unrelated verticals into Qatar work without an approved public decision.
- Preserve source provenance and favor primary sources.
- If records conflict, mark CONFLICT rather than choosing silently.
- Use branches and pull requests for canonical changes.
- Never commit confidential rights, private commercial terms, security details, customer data, or personal data to this public repository.
