# HAMAL Foundry OS

Canonical truth repository for HAMAL and Foundry OS.

## Canonical identity

- **HAMAL** = **H**anzo + **AMA** (Art Mob AGInts) + **L**ux.
- **AMA Solutions Corp** is the commercialization, venture-architecture, and contracting lead unless a signed agreement states otherwise.
- **Hanzo** supplies AI, agent, and cloud infrastructure subject to documented rights.
- **Lux** may supply identity, provenance, and settlement infrastructure where implemented and authorized.
- **Foundry OS** is the operating-system thesis for governed execution, capability evidence, and operator development.
- **MobStack** is the proposed/configurable workflow orchestration layer.
- **Foundry World** is an optional decision-support surface, not a requirement for the first product wedge.
